# Bank Customer Churn Prediction

Проект посвящён прогнозированию оттока клиентов банка с помощью методов
машинного обучения. Цель - оценивать вероятность того, что клиент
покинет банк (`Exited = 1`), на основе его демографических, финансовых
характеристик и истории взаимодействия с банком.


## Постановка задачи

Решается задача бинарной классификации:

-   `Exited = 1` - клиент ушёл из банка;
-   `Exited = 0` - клиент остался клиентом банка.

Модель `CatBoostClassifier` формирует вероятность принадлежности клиента
к классу оттока.

## Данные

[Ссылка на датасет](https://www.kaggle.com/competitions/bank-churn-competition-by-ipii-hs-ex-mts)

 
Исходный набор включает идентификатор клиента, демографические, финансовые и поведенческие характеристики, а также целевой признак Exited.

| Feature | Description | Data Type | Category |
|---|---|---|---|
| CustomerId | Уникальный идентификатор клиента | Integer | Идентификатор |
| Surname | Фамилия клиента | String | Идентификатор |
| CreditScore | Кредитный рейтинг клиента | Numerical | Числовой |
| Geography | Страна проживания клиента | Categorical | Категориальный |
| Gender | Пол клиента | Categorical | Категориальный |
| Age | Возраст клиента | Numerical | Числовой |
| Tenure | Количество лет обслуживания в банке | Numerical | Числовой |
| Balance | Баланс на банковском счёте | Numerical | Числовой |
| NumOfProducts | Количество банковских продуктов | Numerical | Числовой |
| HasCrCard | Наличие кредитной карты (0/1) | Binary | Бинарный |
| IsActiveMember | Активность клиента (0/1) | Binary | Бинарный |
| EstimatedSalary | Предполагаемая заработная плата | Numerical | Числовой |
| Exited | Факт ухода клиента (0/1) | Binary | Целевая переменная |

`CustomerId` и `Surname` исключаются из набора признаков модели. Целевая
переменная - `Exited`.

## Исследовательский анализ и подготовка признаков
**Количественные признаки:**
- Credit Score - кредитный рейтинг
- Age - возраст
- Tenure - количество лет, которое клиент обслуживается в банке
- Balance - баланс на счёте клиента
- NumOfProducts - количество банковских продуктов, которыми пользуется клиент
- EstimatedSalary - предполагаемая заработная плата

**Категориальные признаки:**
- Geography - страна проживания (Франция, Испания или Германия)
  
**Категориальные бинарные признаки:**
- Gender - пол (1 = Male, 0 = Female)
- HasCrCard - наличие кредитной карты (1 = да, 0 = нет).
- IsActiveMember - является ли клиент активным членом банка (1 = да, 0 = нет).

**Таргет:**
- Exited - ушёл ли клиент (1 = да, 0 = нет).

**Можно удалить, так как не несут пользы для определения оттока:**
- Customer ID - уникальный идентификатор
- Surname - фамилия (можно попробовать закодировать)


### Преобразование признаков

Используется `ColumnTransformer`: - `StandardScaler` - для числовых
признаков; - `OneHotEncoder(handle_unknown='ignore')` - для
`Geography`, `AgeGroup` и `QuantityProducts`; - `OrdinalEncoder` - для
бинарных категориальных признаков.

После преобразования обучающая матрица имеет размер **15 000 × 26**.

## Модель и обучение

В качестве алгоритма используется **CatBoostClassifier** - модель
градиентного бустинга на решающих деревьях.

Подбор гиперпараметров выполняется с помощью **Optuna**: - количество
испытаний: 100 (`n_trials=100`); - стратегия: максимизация целевой
метрики; - оценка внутри функции оптимизации: 5-fold cross-validation; -
метрика: ROC-AUC; - случайное состояние: `42`.

Для разделения данных в ноутбуке используется `train_test_split` с
`test_size=0.3` и `random_state=42`. При этом созданная тестовая часть
`X_test`, `y_test` не используется для итоговой независимой оценки
качества.



## Результаты

  | Показатель | Результат |
|---|---|
| Целевая метрика | ROC-AUC |
| Количество испытаний Optuna | 100 |
| Количество фолдов | 5 |
| Лучший ROC-AUC | 0.9322004812841034 |
| Порог классификации | 0.5 |

ROC-AUC оценивает способность модели ранжировать клиентов: насколько
чаще модель присваивает более высокую вероятность оттока действительно
ушедшему клиенту, чем оставшемуся.
